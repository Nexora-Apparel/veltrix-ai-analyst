## Effective shrinkage result

For the unpenalized comparison, the independent calculation used the same optimizer/objective with a 1e-9 ridge as a numerical zero-penalty limit. Per-team ratios are signed fitted effect divided by near-unpenalized reference effect; medians below use absolute ratios to avoid cancellation from sign differences.

- Median absolute attack-effect ratio: 0.0300654 (about 3.01% retained).
- Median absolute defence-effect ratio: 0.0339394 (about 3.39% retained).
- Median attack prior / data information: 30.5764×.
- Median defence prior / data information: 30.3068×.
- Penalized attack-effect population SD: 0.0136711; near-unpenalized reference SD: 0.3651402.
- Penalized defence-effect population SD: 0.0125548; near-unpenalized reference SD: 0.3397125.

Information calculation: for each team's attack parameter, sum the recency-weighted expected goals generated by that team across its fixtures; for defence, sum the recency-weighted expected goals conceded by that team. Poisson Fisher information for a log-rate parameter equals its expected rate. The current summed-objective prior coefficient is divided by this per-team information.

Interpretation: the previous rough estimate that only a few percent of team signal survives is supported. This establishes a measured baseline for the replacement regularization contract; it does not identify an optimal new k or establish predictive accuracy. Ratios around a near-zero reference effect are numerically unstable and must be interpreted team-by-team with their raw effects and information values.

## Controlling architecture amendments

1. Two-tier admission:
   - SHADOW: retrospective gates only; may appear solely in labelled RESEARCH ONLY feed.
   - PUBLISHED: requires prospective settled evidence and explicit user sign-off.
   - `research_shadow_forecast_runs` must reference `model_versions` and the exact report hash; it cannot bypass admission.
2. Database enforcement:
   - Trigger or controlled write function validates admission status and report-hash equality.
   - `config_sha256`, `training_data_sha256` and `evaluation_report_sha256` become immutable after admission.
   - Admission status can only progress from ADMITTED to QUARANTINED.
   - Application DB role receives no direct INSERT on forecast tables; only the controlled write function.
   - API reads join to current admission status so quarantine hides existing forecasts immediately.
3. Test teeth:
   - Recovery and shrinkage tests must fail under the current `team_ridge=0.5`, `competition_ridge=0.5`, half-life 365 configuration.
   - An absurdly large-prior negative control must also fail.
   - The tests must pass a justified corrected configuration and be backed by synthetic known-strength recovery.
4. Evaluation gates:
   - One pre-registered primary metric: 1X2 log loss.
   - Other markets have non-regression checks only until the primary passes.
   - Compute minimum detectable effect and power before evaluation; insufficient power fails admission.
   - Candidate must beat league climatology with home advantage and a tuned team-aware Poisson/Elo baseline.
   - Use nested chronological validation or an untouched holdout, paired block bootstrap by match date, and immutable evaluation-run logging.
   - Final holdout is used once; a failed candidate burns that period.
   - Thresholds require user approval once, then freeze with a hash.
5. Regularization contract:
   - Unnormalized weighted Poisson NLL plus 0.5 × tau × theta².
   - Team attack/defence: tau = k_team × league mean goal rate; one fixed k per parameter type, no per-team k.
   - Competition effect touches both teams' goals; information scale is approximately 2 × league mean goal rate per match.
   - Per-competition home advantage shrinks toward a global home-advantage value; its prior and effective scale must be stated explicitly.
   - Recency weights apply to likelihood, not by changing team-specific prior strengths.
